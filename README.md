# TEG La Revancha — Android (motor PC v16)

**Inicio rápido:** leer [README_ANDROID.md](README_ANDROID.md) para controles, instalación y compilación del APK. El [informe de migración](INFORME_MIGRACION.md) documenta las limitaciones y el plan de validación. La aplicación se desarrolló usando Kivy y el núcleo original Python v16 sin cambios.

Para pruebas del motor: `./ejecutar_pruebas.sh`. Para iniciar interfaz en escritorio (requiere Kivy): `python main.py`. Para compilar APK en Linux/WSL2: `buildozer android debug`.

**El ZIP entregado contiene el proyecto listo para intentar compilar, NO contiene un APK probado.**
